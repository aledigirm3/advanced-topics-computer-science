# Schema Alignment solution using Large Language Models

Schema alignment on multiple database (even different domains) through the use of Large Language Models and prompt engineering techniques.

## Replicate the experiment

Install Python 3.11.11. Execute the following command.

```bash
git clone https://github.com/aledigirm3/advanced-topics-computer-science.git
```

```bash
cd advanced-topics-computer-science/BigData-Integration
```

```bash
pip install -r requirements.txt
```

To replicate the experiment, please refer to the paper included in the repository, which provides a detailed explanation of the pipeline and the scripts used.
