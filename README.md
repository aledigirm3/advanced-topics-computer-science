# Advanced Topics in Computer Science

Assignments of advanced topics in computer science course (Roma 3 University)

## Big Data integration

This assignment aims to design, implement, and evaluate an original schema alignment solution using Large Language Models (LLMs). In particular
to develop a system that, for each natural language question in the BIRD benchmark, identifies
the Source Tables (and the attribute from the source tables)

## Data Lake Management

This project explores a contrastive learning-based solution for searching different versions of tables stored in a data lake.

## Neural Table Representation

This project explores combining SQL with LLMs to handle complex database tasks beyond SQL’s declarative scope. While powerful, this approach faces challenges like inconsistent outputs, high computational costs, and limited scalability.

## Data Centric AI

This project evaluates the reliability of influence-based explanation methods for ML models, focusing on First-Order Influence Functions and TracIn. Using the Titanic dataset, it assesses how consistently these methods identify impactful training samples, aiming to understand their trustworthiness and practical value in model interpretability.

## Active Metadata

Small presentation about metadata, its importance and the use of LLm and AI for generating metadata with considerations on quality of generated metadata
